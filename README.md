# mar_mission — MARS 2099 Mission Control Terminal Game

โปรเจกต์เกมจำลองการเอาชีวิตรอดและบริหารทรัพยากรบนดาวอังคารในรูปแบบ Terminal พัฒนาด้วยภาษา Python สำหรับรายวิชา **CSS111**

## ภาพรวมของเกม
ผู้เล่นรับบทเป็นผู้ควบคุมภารกิจบนดาวอังคาร ต้องเอาชีวิตรอดให้ครบ **5 sols (วัน)** และเก็บ **ตัวอย่างหินอย่างน้อย 3 ชิ้น** โดยบริหารทรัพยากรหลัก 3 อย่างไม่ให้เหลือ 0%:
- **OXYGEN** (ออกซิเจน) — เริ่มต้น 80%
- **ENERGY** (พลังงาน) — เริ่มต้น 60%
- **HULL** (ความแข็งแรงเกราะยาน) — เริ่มต้น 70%

ในแต่ละวันผู้เล่นจะได้เลือกปฏิบัติการ 1 อย่าง จากนั้นจะต้องรับมือกับเหตุการณ์สุ่ม (Random Event) ก่อนจบรอบวัน

## โครงสร้างไฟล์
- `mars_mission.py` — Source Code หลักของเกม
- `test_mars_mission.py` — ชุดทดสอบอัตโนมัติ (Unit Tests & Integration Tests)
- `README.md` — คู่มือการใช้งานและรายละเอียดโปรเจกต์
- `REPORT.md` — รายงานสรุปโครงงาน

## ความต้องการของระบบ
- Python 3.8 ขึ้นไป (ใช้เฉพาะ Standard Library: `random`, `sys`, `unittest`, `io`, `contextlib`)

## วิธีรันโปรแกรม
```bash
python3 mars_mission.py
```

## วิธีรัน Test Case
```bash
python3 -m unittest test_mars_mission.py -v
```
